# Mystical Isles

A player-shaped MMORPG set across a fractured archipelago where exploration, danger, politics, and discovery continually reshape the frontier.

## 🌊 What Is Mystical Isles?
Mystical Isles is a cooperative online fantasy RPG where players sail between unstable islands, survive dangerous frontiers, build influence through settlements and trade, and gradually help define the history of a living world.

## ⚔ Core Gameplay Pillars
- Exploration
- Combat
- Building
- Crafting
- Politics
- Naval Adventure
- Discovery

## 🏝 The World
The archipelago was shattered by The Fracturing, leaving the Mainland Kingdom and the frontier isles locked in a struggle over ruins, routes, relics, and survival. Every island carries a different fantasy, different threats, and different opportunities for players to master.

## 🧱 Player-Driven World
Players influence trade flows, settlement growth, faction power, route safety, and regional access. The world is designed so that exploration, economy, politics, and progression reinforce one another instead of living in isolated feature silos.

## 🛠 Technology Stack
- Unity
- Atavism X 9
- SYNTY POLYGON asset packs
- Gaia + GeNa
- World Streamer
- Supporting MMO middleware and database tooling

## 🚧 Current Development
Current planning is focused on a minimum playable MMORPG: a starter island loop, one city, one dungeon, foundational combat and progression, core crafting and merchants, and the first layer of exploration-led content.

## 📜 Developer Vision
Mystical Isles is built as a long-term social sandbox where systems interlock, world history matters, and player stories become part of the setting itself. Read the full vision here: [Developer Vision](docs/lore/developer_vision.md).
